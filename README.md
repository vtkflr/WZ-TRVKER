# WARZONE TRACKER — Saison 1 • MW4

Application web de suivi de statistiques *Call of Duty: Warzone*, classement et comparaison entre amis, configurations méta, défis hebdomadaires et système de récompenses.

## Fichiers inclus
- `index.html` — Interface complète (Dashboard, Amis, Méta Armes, Défis Hebdo, Modales Match / Compte & Amis / Idées & Bug / Notes MAJ).
- `rewards-system.js` — Gestion des niveaux, XP, titres d'opérateur et emblèmes d'avatar.
- `meta.json` — Configurations d'armes méta et niveaux de déblocage.
- `defis.json` — Liste des défis hebdomadaires et objectifs.
- `manifest.json` & `sw.js` — Configuration PWA et cache.
- `icon-512.png` — Icône de l'application.

## Déploiement sur GitHub Pages
1. Dépose tous les fichiers de ce dossier à la racine de ton dépôt GitHub.
2. Active **GitHub Pages** dans **Settings → Pages** (branche principale, dossier `/root`).
3. Vérifie que les URLs de redirection Google / Supabase correspondent à l'adresse de ton site GitHub Pages.
